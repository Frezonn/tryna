# FrezonMod - Subway Surfers Tweak

تطبيق Tweak متقدم لـ Subway Surfers يوفر قائمة Mod عائمة مع ميزات تحرير العملات المعدنية.

## ✨ الميزات

- 🎮 **قائمة Mod عائمة** - زر عائم يمكن سحبه واستخدامه بسهولة
- 💰 **عملات غير محدودة** - تفعيل/تعطيل العملات المعدنية اللانهائية
- 🎨 **تصميم حديث** - واجهة جميلة وسلسة مع تأثيرات بصرية
- 📱 **متوافق** - يعمل على iOS 13.0+
- 🔒 **آمن** - يحافظ على البيانات الأصلية

## 📋 المتطلبات

- جهاز iOS مع Jailbreak (بروتين + Substrate)
- Theos
- iPhone SDK
- MobileSubstrate

## 🔧 البناء والتثبيت

### البناء
```bash
make clean
make package
```

### التثبيت
```bash
make install
```

### إعادة تشغيل سريعة
```bash
make install
killall SpringBoard
```

## 🚀 الاستخدام

1. ابحث عن الزر الأزرق "FM" في أي مكان على الشاشة
2. اضغط عليه لفتح قائمة Frezon Mod
3. استخدم المفاتيح لتفعيل/تعطيل الميزات
4. اغلق القائمة بالضغط على زر "Close"

## 🐛 التصحيح والسجلات

للتحقق من سجلات الـ Tweak:
```bash
log stream --predicate 'process == "SpringBoard"' --level debug
```

ابحث عن رسائل تبدأ بـ `[FrezonMod]`

## ⚠️ ملاحظات مهمة

- هذا المشروع يستخدم الـ Jailbreak والـ Substrate
- استخدمه على جهازك الخاص فقط
- Subway Surfers قد يحدث تحديثات تؤثر على التوافق
- قم بحفظ نسخة من البيانات الأصلية قبل الاستخدام

## 🔄 الاستعادة

لاستعادة الحالة الأصلية:
```bash
make uninstall
killall SpringBoard
```
